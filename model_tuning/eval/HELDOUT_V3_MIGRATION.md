# Heldout-v3 consumer migration inventory

Heldout-v2 remains the active frozen promotion benchmark until the reviewed Heldout-v3 artifact and provenance manifest are checked in and pass contamination/isolation gates. Do **not** point runtime consumers at candidate files.

This inventory prevents a partial benchmark migration. It was captured from `main` after the deterministic Heldout-v3 freeze tooling landed.

- `model_tuning/config/base_model_candidates_v1.json` — benchmark contract, heldout blob binding, and RAG snapshot binding.
- `scripts/validate-base-model-candidates.py` — validates the benchmark contract.
- `scripts/validate-base-model-research.py` — validates research policy against the active heldout path.
- `scripts/run-base-vs-rag-experiment.py` — experiment benchmark constant.
- `scripts/validate-base-vs-rag-candidate-binding.py` — must continue proving launcher/registry agreement after migration.

- `scripts/audit-required-source-membership.py` — source-membership audit benchmark.
- `scripts/validate-model-eval.py` — default model-evaluation benchmark.
- `scripts/build-grounded-qa.py` — evaluation exclusion boundary; migration must preserve train/eval isolation.
- `scripts/split-model-sft.py` — evaluation exclusion boundary; migration must preserve train/eval isolation.

- `model_tuning/eval/SCORING.md` and `model_tuning/README.md` — frozen-benchmark policy/documentation.

## Promotion gate

A Heldout-v3 promotion change is complete only when all of the following are true:

1. `model_tuning/eval/heldout_v3.jsonl` is generated by `scripts/freeze-heldout-v3.py` from the reviewed 16-case inputs, not hand-edited.
2. Its provenance manifest records the benchmark SHA-256 plus hashes of the candidate pool, final replication pool, source review, and promotion builder.
3. The frozen artifact retains `must_cite`, `source_metadata`, and available `claim_source_bindings`, while candidate workflow fields are absent.
4. Training/evaluation overlap, source-identity isolation, internal duplicate/diversity, citation, and provenance checks pass against the exact frozen bytes.
5. Every runtime/policy consumer above is migrated in the same reviewed change, including the base-model registry's Git blob/hash bindings and the frozen RAG snapshot binding.
6. Repository search confirms no active code/config still treats `heldout_v2.jsonl` as the current benchmark. Historical documentation may mention v2 only when explicitly labeled historical.
7. The previous v2 artifact remains immutable for regression/history; it is not repurposed as training data.
8. Base-vs-RAG, QLoRA, adapter, checkpoint, and model-soup comparisons use the same frozen v3 benchmark contract. No candidate is promoted when citation accuracy, hallucination resistance, or safety-critical diagnostics regress.

## RAG-first rule

Heldout-v3 promotion changes the measurement target, not the training philosophy. Factual/scientific knowledge that can be supplied reliably from reviewed retrieval sources should remain retrieval-grounded. QLoRA/SFT should target measured behavioral residuals such as diagnostic calibration, uncertainty, evidence use, citation discipline, and refusal to universalize experiment-specific findings.
