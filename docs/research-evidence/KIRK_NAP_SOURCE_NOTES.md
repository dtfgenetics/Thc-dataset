# Riley Kirk / NAP / Applied Pharmacognosy Source Migration

Last reviewed: 2026-10-04

## Purpose

This file documents the controlled source families used to seed the research-evidence layer. Machine-readable records live in the research source/study/claim registries. This document is explanatory only and is not a substitute for those records.

## Reuse rules

- Resolve scientific findings to a primary paper, dataset, protocol, or official project page whenever possible.
- Public visibility is not a license. Store rights/access state separately from citation metadata.
- Participant-level human records are not stored in this repository.
- Real-world/observational evidence is never promoted to causal evidence.
- Non-cannabis natural-product studies remain `general_method` or `transferable_non_cannabis`.
- Scientific facts remain retrieval/reference first and `weight_training_eligible=false`.
- Media and supplementary assets require asset-level rights review before redistribution.

## Verified source families

### Network of Applied Pharmacognosy / Real Data Project

The Real Data Project and R-Dub provide a model for longitudinal, repeated real-world observations. The reusable component for THC is the data design: product, dose, route/method, intended purpose, effects, and change over repeated experiences. Public project pages are methodology/context sources; study outcomes should resolve to study-specific primary sources.

### MoreBetter

MoreBetter provides public aggregate study metadata and reports for real-world cannabis studies, including infused beverages. Underlying participant-level data is treated as restricted/metadata-only unless an explicit data-use agreement authorizes access.

### Science of Smokability

Phase I provides a controlled post-harvest example connecting water activity to analytical chemistry and sensory/smoking-quality measures. Phase II public project material is retained as protocol/project metadata only until a results publication is verified.

### Cannabinoid Hyperemesis Syndrome

The 2026 survey paper is retained as observational human evidence for safety/scientific-literacy education. Its convenience sample and self-report design are explicit limitations; reported frequencies are not population risk estimates.

### Longitudinal natural-product RWE methodology

The 2026 Mitragyna speciosa paper is non-cannabis evidence. It is useful only as a transferable longitudinal study-design example: baseline measurement, repeated daily observations, self-selected dose, structured questionnaires, and mixed/repeated-measures analysis.

### Kirk natural-product analytical work

Verified publications cover LC-MS/MS molecular networking, botanical authentication, specimen-linked extract libraries, bioassay-guided screening, natural-product isolation, NMR/mass-spectrometry structure elucidation, and related workflows. These are methodology sources for the chemistry/bioinformatics layer, not cannabis-specific biological evidence.

### GNPS / MassIVE

The Kirk-associated 2022 botanical molecular-networking paper reports public MassIVE accession `MSV000088444` and uses GNPS-style molecular networking. Official GNPS documentation is retained as the infrastructure source for open MS/MS formats, metadata, spectral networking, library search, public dataset publication, and reanalysis.

## Intended application mapping

- **Grow Doc:** longitudinal observations, intervention follow-up, evidence-design labeling.
- **Encyclopedia / Academy:** study-design literacy, claims with scope/limitations, analytical-method explainers.
- **Terpene Atlas:** compound/sample provenance, LC-MS/MS metadata, spectra, molecular families, accession-linked raw data.
- **Plant Atlas / Breeder Journal:** genotype-environment-phenotype-chemistry longitudinal records.
- **Dry/Cure:** water activity and post-harvest measurement design.
- **Beverage education:** aggregate longitudinal cannabis-beverage evidence with observational limitations.
- **Research dashboards:** source/study/claim graph with rights and evidence-state filters.

## Deliberately not migrated

- proprietary or participant-level MoreBetter records;
- direct identifiers or raw human health records;
- copyrighted article text beyond short factual metadata/claims;
- unverified media;
- outcome claims from project/waitlist pages;
- claims that Kirk authored or used a specific analytical tool unless verified by a primary/official source.
